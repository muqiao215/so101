- “这套系统现在可以用一条命令同时拉起 ROS2、后端和前端”

展示点：

### 第 2 段：工单流

展示点：

1. 创建工单
2. 列表出现工单
3. 点击工单看聚焦详情
4. 点击下发

### 第 3 段：状态与检测看板

## 兜底策略

### 方案 A：真实链路优先

适用：

- ROS2 图稳定
- 检测源可用

展示：

- 真实 `/mes_task_status`

### 方案 B：演示注入兜底

适用：

- 相机或检测链路现场不稳定
- 需要快速稳定复现

展示：

- 用 `tools/e2e/run_demo_sequence.sh` 注入工单状态和 red/blue 检测事件
