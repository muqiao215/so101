# E2E-001 启动脚本说明（2026-03-14）

目标：

- 单命令启动 ROS2 仿真链路 + Spring Boot backend + Vue Vite frontend

脚本：

- `tools/e2e/start_e2e_stack.sh`
- `tools/e2e/stop_e2e_stack.sh`

## 启动

```bash
cd /home/muqiao/dev/ros2/workspaces/so101_ws
bash tools/e2e/start_e2e_stack.sh
```

默认行为：

- `use_rviz:=false`
- `use_mock_yolo:=false`
- `enable_rosbridge:=true`

启动完成后，预期端口：

- frontend: `http://127.0.0.1:5173`
- backend: `http://127.0.0.1:8080`
- rosbridge: `ws://127.0.0.1:9090`

日志输出位置：

- `.vscode/.runtime/so101_e2e_ros.log`
- `.vscode/.runtime/so101_e2e_backend.log`
- `.vscode/.runtime/so101_e2e_frontend.log`

## 停止

```bash
cd /home/muqiao/dev/ros2/workspaces/so101_ws
bash tools/e2e/stop_e2e_stack.sh
```

## 可选环境变量

如果需要覆盖默认参数：

```bash
USE_RVIZ=true USE_MOCK_YOLO=true bash tools/e2e/start_e2e_stack.sh
```
