# 机械臂序列编辑器 - 启动指南

## 快速启动
目前依然是不完全版本  连一个像样的前端都没有   但是开头我是通过stitch设置了前端的   这是一个工程能力比较差的作品   还有election的打包也很失败

### 1. 安装依赖

```powershell
cd robotic-arm-sequencer
npm install
```

### 2. 开发模式启动

**方式一：完整开发模式（推荐）**
```powershell
npm run electron:dev
```
这将同时启动主进程、渲染进程和 Electron 应用，支持热重载。

**方式二：分步启动**
```powershell
# 终端 1: 启动主进程构建（监视模式）
npm run dev:main

# 终端 2: 启动渲染进程开发服务器
npm run dev:renderer

# 终端 3: 启动 Electron
npm start
```

### 3. 运行测试

```powershell
# 运行所有测试
npm test

# 运行特定测试文件
npm test -- undo-redo-inverse.test.ts

# 运行属性测试
npm run test:property

# 运行单元测试
npm run test:unit

# 运行集成测试
npm run test:integration

# 监视模式（自动重新运行）
npm run test:watch
```

### 4. 构建生产版本

```powershell
# 构建应用（生成 dist 目录）
npm run build

# 打包为 Windows 安装程序（生成 release 目录）
npm run dist:win

# 或打包为便携版
npm run pack
```

- 进度显示和重试逻辑
- 离线模式设置

## 串口连接

### 连接 Arduino

1. 将 Arduino 通过 USB 连接到电脑
2. 在应用中选择正确的 COM 端口
3. 点击"连接"按钮
4. 状态指示器显示连接状态

### 支持的命令

- **舵机控制**: 6 轴 PWM 控制
- **MP3 播放**: 播放、停止、下一首、上一首、音量
- **批量下载**: 序列数据传输到 EEPROM
- **格式化**: 清空存储槽位
- **离线模式**: 设置开机自动运行

## 故障排除

### 常见问题

1. **串口连接失败**
   - 检查 Arduino 是否正确连接
   - 确认 COM 端口号正确
   - 关闭其他占用串口的程序（如 Arduino IDE）
   - 检查驱动程序是否安装

2. **应用无法启动**
   - 删除 `node_modules` 和 `dist` 目录
   - 重新运行 `npm install`
   - 检查 Node.js 版本（需要 v22.21.0）
   - 运行 `npm run clean` 清理缓存

3. **构建失败**
   - 清理构建缓存: `npm run clean`
   - 重新安装依赖: `rm -rf node_modules && npm install`
   - 检查 TypeScript 错误: `npm run lint`

4. **测试失败**
   - 运行 `npm test` 查看详细错误
   - 检查 `TEST_VALIDATION_SUMMARY.md` 了解已知问题
   - 当前测试通过率: 95% (266/280)

5. **开发服务器端口被占用**
   - 查找占用端口的进程: `netstat -ano | findstr :8080`
   - 结束进程: `taskkill /F /PID <进程ID>`
   - 或修改 `package.json` 中的端口号（默认 8080）

6. **better-sqlite3 模块版本不匹配**
   - 错误信息: "The module was compiled against a different Node.js version"
   - 解决方法: `npm rebuild better-sqlite3`
   - 如果仍有问题: `npm install --force`
   - ⚠️ 当前状态: 数据库功能暂时不可用，应用会显示警告但继续运行

7. **TypeScript 编译错误**
   - 确保已安装类型定义: `npm install --save-dev @types/better-sqlite3`
   - 运行类型检查: `npx tsc --noEmit`
   - 查看诊断信息定位具体错误
   - ✅ 已修复: 所有 36 个编译错误已解决

8. **黑屏问题**
   - ✅ 已修复: 创建了缺失的 `src/renderer/styles/index.css`
   - ✅ 已修复: 禁用了 Electron 沙箱模式解决兼容性问题
   - 如果仍有黑屏，按 `Ctrl+Shift+I` 打开开发者工具查看控制台错误
